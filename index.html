A web app can't check location while it's closed. For that, set up a phone automation (iPhone Shortcuts → Automation → "When I arrive") that opens one of these links — it works even with the app closed:

How to set up the arrival automation (per site)
  1. Shortcuts app → Automation → + → Arrive.
  2. Location: search the prison / PDC address. Time range: 9:00 AM – 2:00 PM. Choose Run Immediately, turn off "Notify When Run".
  3. Next → New Blank Automation → add action Get Contents of URL → paste the site's link copied above.
  4. Done. Repeat for each facility. The link only does anything Mon–Thu 9am–2pm, and never overwrites a day that already has miles.
